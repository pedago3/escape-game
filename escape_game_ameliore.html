⏱️ 45-60 minutes 👥 Équipes de 3-4 🎯 5 énigmes

📖 LE SCÉNARIO

Ce matin, en arrivant au lycée, vous découvrez que le précieux échantillon de cuivre pur du laboratoire a disparu ! Le Professeur Réductor, votre enseignant de chimie, est catastrophé : cet échantillon devait servir à la démonstration de demain devant l'inspecteur.

Heureusement, le voleur a laissé des traces de réactions chimiques sur son passage. En utilisant vos connaissances en oxydoréduction et en bilan de matière, vous devez reconstituer le parcours du voleur, retrouver l'échantillon et identifier le coupable.

⚠️ Vous avez 1 heure avant l'arrivée du gardien. À vous de jouer !

ÉNIGME 1/5 La trace sur la porte

Oxydant, réducteur et transfert d'électrons

📋 Contexte

Sur la poignée de la porte du laboratoire, vous découvrez une trace verdâtre. Le Professeur Réductor vous explique que c'est du vert-de-gris, formé par l'oxydation du cuivre au contact de l'air. Quelqu'un a manipulé du cuivre récemment !

Question A : L'ion Fe³⁺ capte un électron pour devenir Fe²⁺. L'ion Fe³⁺ est-il un oxydant ou un réducteur ?

Question B : Le cuivre Cu perd 2 électrons pour devenir Cu²⁺. Le cuivre subit-il une oxydation ou une réduction ?

ÉNIGME 3/5 Le message dans le coffre

📚 Notion mobilisée

Équation d'oxydoréduction complète

📋 Contexte

Dans le coffre, vous trouvez une feuille avec une équation d'oxydoréduction incomplète et un message codé. Le voleur a laissé cette trace en faisant une manipulation !

❓ L'énigme

Le voleur a plongé une lame d'argent dans une solution d'ions cuivre Cu²⁺.

Les couples redox sont : Ag⁺/Ag et Cu²⁺/Cu

Étape 1 : Écrivez les deux demi-équations électroniques.

Étape 2 : Équilibrez le nombre d'électrons (coefficient multiplicateur ?).

Étape 3 : Écrivez l'équation bilan complète.

Demi-équation de réduction :

Ag⁺ + e⁻ → Ag

Demi-équation d'oxydation :

Cu → Cu²⁺ + 2e⁻

🔑 Le code = coefficient devant Ag⁺ dans l'équation bilan

ÉNIGME 4/5 Le tableau mystérieux

📚 Notion mobilisée

Tableau d'avancement et évolution du système

📋 Contexte

Dans la salle 2, vous trouvez un tableau blanc avec un tableau d'avancement partiellement effacé. C'est la trace d'une expérience que le voleur a réalisée !

❓ L'énigme

2Ag⁺ + Cu → 2Ag + Cu²⁺

n(Ag⁺)ᵢ = 0,1 mol n(Cu)ᵢ = 0,08 mol n(Ag)ᵢ = 0 mol n(Cu²⁺)ᵢ = 0 mol

Complétez le tableau d'avancement en fonction de x :

État 2Ag⁺ Cu 2Ag Cu²⁺
EI 0,1 0,08 0 0
x

🔢 Code = nombre de termes parmi A, B, C, D qui contiennent « 2x »
